# WWFTidalFlats
Using murrays approach to calculate tidal flats for yellow sea bird habitat change.

## GIT RULEZ
-  switch to dev
  > git switch dev
- create a feature branch for your own work.
  - either via the GUI in vscode or
  - > git switch -b your-branch-name
- if you want to integrate new changes from remote, please merge from `dev` branch. do that by:
    - > git fetch
    - > git merge --no-ff origin/dev 
- for integrating your own work into `dev`, please open a pull request.
  - go to github > WWFTidalFlats > Pull Requests
  - open PR your-branch-name -> dev
  - assign me as reviewer, wait for my review 
- I will handle review etc. 🤓
